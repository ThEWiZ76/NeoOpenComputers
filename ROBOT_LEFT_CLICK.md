# Robot left click and hit calibration

Upstream Agent.swing accepts local action sides down/up/front (0/1/3), optional face calibration except the opposite side, and optional sneaky boolean. Its pick ray starts half a block along facing, targets .51 farther plus the calibrated side times swingRange (.49 default), tries facing then non-opposite faces when omitted, and reports the actual hit face. Player.clickBlock routes through the normal left-click interaction path.

Port now validates those sides, raycasts OUTLINE/Fluid.NONE with the same offsets/order, and defines robot.swingRange default .49. Loaded adjacent/end positions are checked. Sneaking is applied to the borrowed survival fake player, carried in the queued DigTask, and restored after both startup and harvest. Startup checks mayInteract/blockActionRestricted and posts CommonHooks.onLeftClickBlock START with the actual hit face and equipped tool. Cancellation/useItem FALSE reject the dig. useBlock FALSE only suppresses BlockState.attack; allowed attack runs and the resulting state becomes the queued target, so redstone ore lighting does not invalidate its own dig. If attack itself removes the block, return successful block interaction with short pause/animation.
