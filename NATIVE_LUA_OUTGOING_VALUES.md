# Native Lua outgoing values

Runtime: ddfad17850e45d96395713d3571ca7c03598423a; verified 2026-10-20. Upstream contract: util/ExtendedLuaState.scala pushValue/pushList/pushTable. Characters become strings, byte arrays remain binary strings, other arrays become one-based tables, and a per-root identity memo preserves shared/cyclic maps and arrays.

NativeLuaValues previously rejected primitive arrays other than byte[] and Character, duplicated shared tables and rejected cycles at the nesting guard. A failed conversion also left a partial table/key on the Lua stack. The shared outgoing codec now handles reflection arrays and characters, keeps temporary Lua registry references for graph identity, releases them in finally and restores the entry stack on failure. The 64-level guard for new descents remains; a reference back to an already visited table closes a cycle without descending again. Null map keys are skipped, matching upstream. No persisted format or dependency changed.
