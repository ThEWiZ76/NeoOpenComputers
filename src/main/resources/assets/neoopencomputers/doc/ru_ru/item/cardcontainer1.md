# Контейнер для карт

![Может хранить карты!](oredict:oc:cardContainer1)

Контейнер для карт - улучшение-контейнер для роботов, позволящее вставлять и извлекать карты из роботов без пересборки. Максимальный уровень карты равен уровню контейнера. В отличие от обычных улучшений, требуемая сложность сборки двойная. Подробнее о сложности сборки смотрите здесь.
