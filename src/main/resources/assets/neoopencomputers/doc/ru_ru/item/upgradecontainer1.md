# Контейнер для улучшения

![Может хранить улучшение.](oredict:oc:upgradeContainer1)

Это улучшение-контейнер для роботов, добавляющее собранным роботам слот под установку еще одного улучшения. Максимальный уровень улучшения, которое может быть установлено, равен уровню контейнера. Прочтите документацию о роботах и [сборщике](../block/assembler.md) для информации о требуемой сложности сборки.
