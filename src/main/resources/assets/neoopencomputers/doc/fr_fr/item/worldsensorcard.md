# Carte de capteur du monde

![Au mépris du danger... Aller là où aucun homme n'est jamais allé auparavant.](oredict:oc:worldSensorCard)

La carte de capteur du monde permet de lire les informations atmosphériques ainsi que la gravité des différentes planètes ajoutées par Galacticraft. Cela peut être utile pour les robots ou les drones travaillant dans l'espace.
