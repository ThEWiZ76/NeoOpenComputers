# Drohne

NeoOpenComputers alpha unavailable: this upstream device page is kept for reference, but this device is not available in the current alpha build.

Drohnen werden mit einem Drohnengehäuse in der [Elektronik-Werkbank](../block/assembler.md) gebaut. Sie sind entitybasierende Roboter, allerdings ein bisschen günstiger und mit eingeschränkter Funktionalität. Sie können sich zudem weitaus schneller bewegen als Roboter und werden über ein Clientprogramm auf einem Computer gesteuert. Die Drohne benötigt ein konfiguriertes [EEPROM](eeprom.md) um Befehle zu empfangen oder selbst zu arbeiten.
