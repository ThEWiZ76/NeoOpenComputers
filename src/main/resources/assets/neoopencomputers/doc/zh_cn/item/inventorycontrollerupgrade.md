# 物品栏交互升级

![尽在我的控制之中。](oredict:oc:inventoryControllerUpgrade)

物品栏交互升级为机器人和无人机提供了更进一步的物品栏交互能力。它能让设备在从外部容器存取物品时指定具体槽位、读取物品堆的详细信息，还能让机器人可以不借助外力更换自身装备。

该升级还可以装入[适配器](../block/adapter.md)中，可为[适配器](../block/adapter.md)提供类似提供给机器人的，探测相邻物品容器的能力。但不能让[适配器](../block/adapter.md)从容器中存取物品，此特性仅适用于机器人和无人机。

另见：[转运器](../block/transposer.md)。
