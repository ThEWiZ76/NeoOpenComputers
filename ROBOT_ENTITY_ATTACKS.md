# Robot entity attacks

Upstream reference: server/component/Agent.scala swing/pick and server/agent/Player.scala closestEntity/attackTargetEntityWithCurrentItem. Pick searches the adjacent full block bounds, compares the nearest eligible entity against block-hit distance, and retries with a living entity when a ray misses. Eligible direct targets are living entities, minecarts and drones. A targeted but canceled attack still returns true/entity and incurs swing delay. Minecarts receive at most eleven attack attempts. Player attacks are disabled by robot.canAttackPlayers=false.

The port now selects entities before the block fallback. It borrows the survival fake player with the equipped tool and sneaking/ground state, applies tool attribute modifiers for the action because this fake player does not tick equipment, and restores previous modifiers/state afterwards. RobotAttackEntityEvent.Pre cancellation gates normal Player.attack (including NeoForge protection); Post follows an allowed attempt. Actual changed tool wear passes through existing RobotUsedToolEvent handlers. New drops use cargo collection with pickup hooks and overflow preservation. Entity swings pause and animate using robot.delays.swing.

Initial robot-entity-red.log reproduced both absent targeting and absent protection hook. Tests cover actual living-target damage, robot cancellation with tool/sneak state and restored borrowed player, NeoForge cancellation with sword attributes present and then restored, no tool wear on cancellation, disabled/enabled player hook gating, nearer-block occlusion and minecart destruction/drop collection. Player-option test deliberately cancels the enabled attack at Pre; actual player damage/PvP behavior remains to be verified.

Remaining entity parity: living-kill XP and experience-upgrade handling, exact repeated-attack/cooldown and enchantment behavior, live combat/tool animation, player damage under server/team rules, modded entity/drop callbacks and action persistence. Existing vanilla FakePlayer has no ticking attack timer; do not infer full combat parity from a successful damage test. This checkpoint implements targeting and the attack/event path, not the entire entity parity requirement.
